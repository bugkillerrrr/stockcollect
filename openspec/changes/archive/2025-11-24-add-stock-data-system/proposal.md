# 变更：构建量化交易股票数据系统（技术数据+财会数据整合）

## Why
我需要一个量化交易程序来测试交易策略，作为学生只有一台电脑，需要解决：
1. 2018年至今的股票技术数据（价格、成交量等）收集
2. 财会数据（财务报表）的收集和存储
3. 两种数据的有效结合和关联，便于策略分析
4. 单机环境的轻量级解决方案
5. 日常数据更新机制

## What Changes
- **新增：** 股票技术数据收集模块（日线、分钟线等）
- **新增：** 财会数据收集模块（资产负债表、利润表、现金流量表）
- **新增：** 统一的数据存储设计，支持技术数据和财会数据的关联查询
- **新增：** 基于股票代码+时间戳的数据关联机制
- **新增：** 自动化数据更新和同步系统
- **新增：** 轻量级本地存储方案（SQLite + 文件存储）
- **新增：** 数据查询接口，支持跨数据类型的分析
- **新增：** 基础回测框架，支持多数据源策略

## 影响
- 新增能力：股票数据收集、财会数据整合、策略回测
- 核心设计：统一数据模型，支持技术指标和财务指标的联合分析
- 影响代码：完整的项目架构（新项目）
- 技术栈：Python + SQLite + Pandas + 免费数据API
- 数据源：tushare、akshare、yfinance等免费API

## 核心设计重点
- **数据关联：** 通过股票代码统一技术数据和财会数据
- **时间对齐：** 处理财会数据（季度）和技术数据（日线）的时间频率差异
- **查询效率：** 支持按股票、时间范围、数据类型的灵活查询
- **扩展性：** 便于后续添加更多数据类型（如行业数据、宏观数据）
- **存储优化：** 针对单机环境，平衡存储空间和查询性能

## 约束条件
- 单机环境，无外部数据库
- 学生预算，优先免费数据源
- 数据时间范围：2018年至今
- 支持每日/定期自动更新
- 财会数据和技术数据必须能有效关联使用
